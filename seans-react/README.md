# Сеанс — React-версия (лабораторная работа №2)

Вёрстка из лабораторной №1 перенесена в компоненты React. Стили (`src/index.css`)
не менялись — только разметка разбита на переиспользуемые части.

## Запуск

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173`. Доступные маршруты:

- `/` — главная страница
- `/watch` — комната совместного просмотра (рабочий чат: можно печатать и отправлять сообщения)
- `/auth` — вход и регистрация (переключение вкладок без перезагрузки страницы)

## Сборка

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`.

## Структура компонентов

```
src/
  components/
    SiteHeader.jsx    — шапка маркетинговых страниц
    SiteFooter.jsx    — подвал сайта
    AvatarStack.jsx   — стопка аватаров зрителей
    RoomHeader.jsx    — шапка комнаты просмотра
    VideoPlayer.jsx   — блок плеера с элементами управления
    ChatMessage.jsx   — одно сообщение чата (системное или обычное)
    ChatPanel.jsx      — чат целиком: состояние сообщений + отправка
    AuthForm.jsx       — форма входа/регистрации с переключением вкладок
  pages/
    HomePage.jsx
    WatchPage.jsx
    AuthPage.jsx
  App.jsx    — маршрутизация (react-router-dom)
  main.jsx   — точка входа
  index.css  — стили из лабораторной №1
```
